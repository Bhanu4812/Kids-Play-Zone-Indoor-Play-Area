WonderNest Play Website

A responsive, accessible multipage website for an indoor children’s play center.

Getting Started

  1. Open pages/index.html.
  2. No build process or backend is required.
  3. Serve through any static web server for best results.

Project Structure

Public pages live in pages/. Shared style and scripts are in assets/css/ and assets/js/.

Brand & Theme

Update colors and spacing in variables.css. Dark mode follows the system until a visitor stores a preference.

RTL

Add dir="rtl" to any HTML element. The shared RTL stylesheet adjusts navigation, forms, tables, and dashboard placement.

Forms

Forms use client-side demo validation and simulated success states. Connect submit handlers to your production API.

Images

Current content uses remote editorial image URLs. Replace these with optimized local WebP assets before production deployment.

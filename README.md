# WonderNest Play

A complete static multipage website for a premium kids indoor play center. The project lives directly in the existing `Kids Play Zone & Indoor Play Area` folder.

## Start

Open `pages/index.html` or serve the project root with a static development server.

## Included pages

- Two distinct homepages
- Play zones with age filtering
- Birthday parties with validated enquiry form
- Membership, safety, about, and contact
- Login and registration
- Parent dashboard with multi-step booking
- Admin operations dashboard
- 404 and coming-soon pages
- Project documentation

## Features

- Responsive layouts from 320px through large desktops
- Persistent light/dark theme
- Expandable mobile navigation and Home dropdown
- Accessible accordions, forms, focus states, and modal behavior
- RTL stylesheet
- Demo validation, filters, booking flow, exports, and loading states
- SEO metadata, sitemap, robots file, and LocalBusiness schema

## Production notes

The site is backend-free. Connect form and authentication handlers to your own API. Remote image URLs should be downloaded, licensed, and optimized to local WebP files before production use.
